# The Ant extension gives VS Code completion, diagnostics, navigation, formatting, and debugging.

<p class="actions"><a class="button" href="https://marketplace.visualstudio.com/items?itemName=ant-lang.ant-lang">Install from the Visual Studio Marketplace</a></p>

<section class="feature">
<div class="text">

## Completion, with signatures.

Names in scope, the fields of a record after `.`, and the functions a pipe can continue with after `|`, each with its signature.

</div>

<div class="text">

## Errors as you type.

An error appears as you type, with its message on hover and in the Problems panel, and goes away with the fix.

</div>
<div class="shot">
<Preview src="/ide/vscode/diagnostics.mp4" />
</div>

</div>

Ant: Run File runs the current file with `ant run`. A task of type `ant` can be the default build task.

</div>
<div class="shot">
<Preview src="/ide/vscode/run.mp4" />

<div class="text">

In a test file, run test and debug test code lenses stand above each test and each subtest, and the output shows what failed.

</div>
<div class="shot">
<Preview src="/ide/vscode/tests.mp4" />
