Ant 0.3.1 and 0.3.2 bring the rest of the toolchain to WebAssembly, so a page that embeds Ant can
do what the command line does.

## Tests

`ant.wasm` runs test files as `ant test` does and reports each event of `ant test -json`. The
[Ant Editor](https://editor.ant-lang.org) uses it: a test file runs its tests, and a lens above each
test runs that one.

```ant
func sum(xs: Array[int]): int {
  var total = 0
  for x in xs {
    total += x
  }
  total
}

test "sum adds every number" {
  assert(sum([1, 2, 3]) == 6)
}
```

```txt
ok    1 passed (0.00s)
```

## The debugger

`ant.wasm` also exposes the debugger as a Debug Adapter Protocol session over messages, as it does
the language server. Output written in small pieces now shows on time, instead of waiting for a
batch to fill.

## Also new

- Install on Windows in PowerShell:

  ```powershell
  irm https://ant-lang.org/install.ps1 | iex
  ```

- Completion after a `Result` offers the `Result` functions, such as `Result.unwrap`.

There are no language changes. The packages are on npm as
[@ant-lang/wasm](https://www.npmjs.com/package/@ant-lang/wasm) and
[@ant-lang/monaco](https://www.npmjs.com/package/@ant-lang/monaco) 0.9.0.
