# The Ant plugin gives IntelliJ IDEA completion, diagnostics, navigation, run configurations, tests, and debugging.

<p class="actions"><a class="button" href="https://plugins.jetbrains.com/plugin/35684-ant-language">Install from the JetBrains Marketplace</a></p>

</header>

<div class="text">

Names in scope, the fields of a record after `.`, and the functions a pipe can continue with after `|`, each with its signature and its documentation.

<div class="text">

## Run from the gutter.

The run icon runs `ant run` with the file in the Run tool window. Only a script, a file with a statement at its top level, has the icon.

</div>
<div class="shot">
<Preview src="/ide/intellij/run.mp4" label="Run from the gutter in IntelliJ IDEA" />
</div>
</section>

<section class="feature">
<div class="text">

## Run one test from the gutter.

In a test file, each test and each row of a table has a run icon. Run there runs that test alone into the test tree, and the icon remembers how it last went.

</div>
<div class="shot">
<Preview src="/ide/intellij/tests.mp4" label="Run one test from the gutter in IntelliJ IDEA" />
</div>
</section>

<section class="feature">
<div class="text">

## Debug a run configuration.

Breakpoints with conditions and logged expressions, frames and variables, values on hover, stepping, and the console. Ant Panics in the Breakpoints dialog stops at a panic nothing catches.

</div>
<div class="shot">
<Preview src="/ide/intellij/debugging.mp4" label="Debug a run configuration in IntelliJ IDEA" />
